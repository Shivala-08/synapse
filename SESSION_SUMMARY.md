### 2.4 LLM Model Fix

**Fix:** Switched to `meta/llama-3.2-11b-vision-instruct` — fast (~3s/question), accurate, available on NVIDIA NIM.

**Files changed:**

## 8. Key Learnings

1. **NVIDIA NIM models deprecate without warning** — `meta/llama-3.1-8b-instruct` was end-of-life for a week before we discovered it. Always verify model availability.
2. **Smart-context fallback hides LLM failures** — when the LLM fails, the system silently echoes raw source text. This made it look like retrieval was "working" when actually the LLM wasn't generating answers.
3. **User-provided QA pairs are better** — the user's 45 questions from `second-brain/qna-pairs/` are more exam-realistic than AI-generated ones.
4. **PPTX parsing works** — `python-pptx` successfully extracts slide text, tables, and speaker notes for RAG ingestion.
